## 3. 回归实测（固定 50 条测试集，判定标准：交付链路 0 违例）

### 3.1 检查器规则修正（宁漏勿错报原则）

首测新模型 76 违例，逐条分析后发现其中 72 条为规则误报：

| 规则问题 | 处理 |
|---|---|
| 「...」被判省略号/中英混用 | 「...」为产品设计稿金标回复既定风格（如「嗯...考砸了确实很难受呢」），不再计违例；只抓「。。」 |
| 「真地」白名单误伤「认真地想了想」 | 移除该词（低精度） |
| 圈号 ①② 被判乱码 | 圈号序列（U+2460-U+24FF）加入合法字符 |

修正后自测：真实错误（悬挂连词、句号连用、半角标点混用、重复字、连词堆叠、括号未闭合）仍全部命中。

## 4. 检索输出功能（新增）

按「对话内容 + 记忆」检索知识库并适量输出：

- `knowledge_service.get_relevant_knowledge_for_chat`：检索查询 = 当前消息 + 最近 8 条历史用户消息（对话）+ 用户画像文本（记忆），问题类型关键词基于整段对话检测；top-3、单条 ≤240 字、总量 ≤800 字封顶（适量）。
- 回复生成：检索结果注入 System Prompt，指令「每次只融入 1-2 个关键点、不要整段照搬」。
- 响应透出：`ChatResponse` 新增 `knowledge_hits` 字段（命中知识标题），便于观测检索输出。
- 修复两处既有缺陷：
  1. `KnowledgeService.__init__` 中 fallback 标记被后续赋值覆盖，导致降级路由失效（已调整初始化顺序）。
  2. `chat_service` 自建独立知识库实例导致 RAG 永不命中（已改为共享注入同一实例）。
- 输出侧兜底：`auto_fix` 排版归一化 + 清理偶发方括号伪标签（如 `[自动分隔情绪]`）与幻觉 URL。

实测：`POST /chat`（消息「压力大，朋友建议正念放松」+ 历史 + 画像）→ `rag_enhanced=true`，命中 3 篇知识（正念冥想在心理治疗中的应用 等），回复适量融入正念要点，语法干净、无幻觉链接。
