# AI Agent 桌面客户端 · UI / 前端设计规范 v0.3

> 面向**完全不懂代码的普通人**的 AI Agent 桌面工作台。
> 依据：微信 Windows 客户端逆向报告、DeepSeek Harness 桌面端逆向报告。
> 配套原型：`prototype.html`（同目录，单文件零依赖）。

---

## 1. 产品定位与人格

**一句话**：说一件事，它帮你做完，你随时能看见、能叫停。

| 关键词 | 含义 | 反面（禁止） |
| --- | --- | --- |
| 好懂 | 每一屏都能用日常语言回答"它在做什么 / 我该做什么" | 术语堆砌、日志直出 |
| 可信 | 动文件前必问、危险动作有代价、数据在哪能查 | 静默执行、模糊确认 |
| 有分寸 | 能力全都在，但只在需要时出现 | 满屏开关、常驻指标 |

**人格设定**：一位做事利落、说话简短的助理。不卖萌，不邀功，不解释自己有多聪明；做错了直接说"我搞砸了，可以这样补救"。

**语气规范**

- 用动词开头：`正在整理第 3 段`，而不是 `文本处理中`。
- 说结果不说机制：`已保存到「会议纪要」文件夹`，而不是 `写入成功 /path/to/file`。
- 报错给下一步：`网络断了，正在重试（第 2 次）`，并在下方给「换用手机热点」这类可执行动作。
- 不用感叹号，不用 emoji，不用"亲"。

## 2. 用户画像与阅读能力

| 维度 | 设定 |
| --- | --- |
| 是谁 | 写作者、学生、行政、个体经营者、家庭用户 |
| 会的 | 打开应用、点按钮、填表单、拖文件、看进度条、复制粘贴 |
| 不会的 | 读日志、判断命令是否危险、理解权限位、配置环境变量 |
| 不认识的概念 | API、token、上下文窗口、沙箱、进程、凭据、插件 |
| 怕的 | ① 文件被乱改 ② 电脑被弄坏 ③ 看不懂报错 ④ 被扣钱 |
| 想要的 | 交办 → 看得见进度 → 不对劲能叫停 → 结果找得到 |

**阅读能力假设**：能顺畅读 15px 中文正文；能理解两行以内的说明；不会主动点开"高级"字样。因此**关键信息必须在零点击处可见**，详情只能是"锦上添花"，不能是"必要条件"。

**由此确立第一原则**

> 能力可以强，但界面只说人话；技术细节一律**折叠而非删除**——想深究的人点开就有，不想看的人永远不用看见。

## 3. 信息架构

6 个视图 + 1 个命令面板。任意位置 2 步内可达「权限范围 / 我的文件 / 账号」。

```
我的任务（首页）
├─ 任务进行中 ── 需要你确认（覆层）── 详情抽屉（默认收起）
├─ 我的文件（产物 / 空间 / 自动清理）
├─ 账号与奖励
└─ 设置与帮助（外观 / 解释粒度 / 网络 / 隐私 / 诊断）
```

| 视图 | 用户来这儿要解决什么 | 固定入口 |
| --- | --- | --- |
| 我的任务（S1） | "我要它做件新事" / "上次那个呢" | 任务栏顶部 ＋ 新任务 |
| 任务进行中（S2） | "它做到哪了 / 我能叫停吗" | 点任意任务 |
| 需要你确认（S3） | "它要动我的东西，我同意吗" | 任务流中自动弹出 |
| 我的文件（S4） | "结果存哪了 / 空间还够吗" | 任务栏底部 |
| 账号与奖励（S5） | "我登录了吗 / 有没有红包" | 标题条右侧头像 |
| 设置与帮助（S6） | "字太小 / 想看点细节 / 网怎么了" | 标题条右侧齿轮 |

**导航规则**：任一视图都可 `Esc` 回到上一层；任务栏常驻不折叠（用户靠它认路）；不使用汉堡菜单隐藏主导航。

## 4. 人话词典（强制）

所有界面文案必须按此表转译。**简明模式下，左列技术名不得出现在任何可见文案中。**

| 技术名 | 界面用词 | 一句话解释（可展开） |
| --- | --- | --- |
| 沙箱 `read-only` | 只看看 | 它只能读，不能改任何文件 |
| 沙箱 `workspace-write` | 可以改这个文件夹 | 只有这个文件夹里的东西它能改 |
| 沙箱 `danger-full-access` | 什么都能动 | 整个电脑都允许它改，用完 30 分钟自动收回 |
| 工具审批 / MANDATORY_IPC | 需要你点一下头 | 动文件、上网之前先问你一句 |
| token / 上下文窗口 1M·256K | 记忆用量 37% | 这次对话它还能记住多少内容 |
| 凭据 / CredentialKey / 环境变量 | 已连接的账号 | 你授权过的服务，随时可断开 |
| 273 个插件 | 能力 | 会写作、看表格、查资料等，用不到就不开 |
| `session.v4.jsonl` | 任务记录 | 任务存在你电脑上，可续、可导出 |
| 命名信号量锁 | 正在另一个窗口进行中 | 同一个任务不会两边同时改 |
| Files 25GB / 10000 / 7 天 | 文件空间 21GB 可用，7 天后自动清理旧文件 | 帮你自动腾地方 |
| Cronet / gquic / Mars | 网络：正常 | 大文件、实时消息走不同通道 |
| 奖励钱包 `get_unnotified_bonuses` | 有 2 个红包待领取 | — |
| 日志 | 运行记录（可导出） | 出问题时给客服看 |
| 用户目录 `~/.dsh` | 这台电脑上 | 你的任务和数据都存在本地 |
| 匿名 UUID | 匿名编号 | 不关联你的真实身份 |

### 禁用词表（简明模式可见文案零容忍）

```
沙箱  token  上下文  IPC  进程  线程  凭据  API  Key  插件
JSONL  zstd  AES  Cronet  QUIC  Mars  信号量  挂载  环境变量
fallback  endpoint  schema  实例  参数  回调  并发  缓存
```

例外：出现在「查看详情 / 诊断 / 运行记录」展开后允许；出现在用户自己输入的内容里不算违规。

### 三档解释粒度

| 层级 | 谁看 | 典型文案 | 默认状态 |
| --- | --- | --- | --- |
| L1 人话层 | 所有人 | `AI 想把 3 个文件改名` | **总是可见** |
| L2 明细层 | 好奇的人 | 具体文件名、耗时、步数、用了哪个能力 | 点「查看详情」后可见；详细模式自动展开 |
| L3 技术层 | 极少数 | 命令原文、路径、模式名、日志 | 需在 L2 内**第二次点击**「查看具体操作」|

全局开关「简明 / 详细」（默认简明）只控制 L2 是否自动展开；L3 永远需要主动点两次。

### 5.4 非颜色令牌（三套气质共用）

| 令牌 | 值 |
| --- | --- |
| 圆角 | `--r-1:2px`、`--r-2:4px`、`--r-3:6px`（**没有更大的**） |
| 间距基线 | 8px；允许 `4 / 8 / 12 / 16 / 24 / 32 / 48 / 64` |
| 阴影 | `--shadow-1: 0 1px 2px rgba(26,25,18,.06)`；`--shadow-2: 0 8px 24px -12px rgba(26,25,18,.28)`；浮层才用 |
| 描边 | `--border: 1px solid var(--line)`；选中改用 `--accent` |
| 动效时长 | `--t-fast:120ms`、`--t:200ms`、`--t-slow:360ms` |
| 缓动 | `--ease: cubic-bezier(.2,.7,.2,1)` |

### 5.5 断言（评审可直接否决的红线）

1. **禁止**紫色渐变、玻璃拟态（`backdrop-filter`）、胶囊大圆角（`border-radius ≥ 8px` 只允许用于头像与状态点）。
2. 主色只做点睛：单屏主色面积不超过可视面积的 5%，不做大面积色块填充。
3. 不用纯黑 `#000` 与纯白 `#FFF` 作为大面底色（A 气质浅色里 `#FFF` 只用于浮层）。
4. 不用图标替代文字做主操作；主按钮一律「图标 + 文字」。
5. 颜色不单独承载状态含义：状态同时用文字或形状（节点空心/实心）。

## 6. 字体

| 角色 | 字体 | 回退 | 用途 |
| --- | --- | --- | --- |
| 展示 | **Fraunces**（`opsz 9..144`、`wonk`） | `Noto Serif SC`, serif | 品牌名、任务名、空状态标题、大数字 |

| 正文 | 15 / 1.55 / 400 |
| 次要说明 | 13 / 1.6 / 400 |

| 页面标题 | 28 / 1.25 / 600（Fraunces） |
| 空状态大标题 | 38 / 1.2 / 600（Fraunces） |

## 7. 栅格与布局

**8px 基线**，所有间距为 8 的倍数（4px 仅用于图标与文字间隙）。

```
┌ 48px 自定义标题条（可拖拽）：‹ 我的任务 ─ 网络·正常 ─ 简明/详细 ─ 设置 ┐
├ 248px 任务栏 ─────┬ 自适应中栏（≥560）─────────────┬ 320px 详情抽屉（默认收起）┤
│                    │                                 │                          │
└────────────────────┴─────────────────────────────────┴──────────────────────────┘
```

| 区域 | 尺寸规则 |
| --- | --- |
| 标题条 | 固定 48px 高；左侧返回 + 当前视图名；右侧网络点、粒度开关、设置 |
| 任务栏 | 固定 248px；可折叠到 64px（仅图标 + 悬浮提示）；不建议隐藏 |
| 中栏 | `flex:1`，最小 560px；≥1920 时内容最大 880px 且居中 |
| 详情抽屉 | 320px，默认收起；展开时中栏让位（不覆盖），Esc 关闭 |
| 窗口 | 最小 1280×800；不做移动端断点 |

**纵向节奏**：标题条下 24px 起内容；步骤卡之间 12px；分组之间 32px；页面底部留 64px。

## 8. 组件清单与契约

每个组件含：尺寸 / 状态 / 键盘 / 无障碍。所有交互元素命中区 **≥ 40px**。

### TitleBar

- 48px 高，`-webkit-app-region: drag`；内部按钮 `no-drag`。
- 左：`‹` 返回（有上一层时出现）+ 视图名（Fraunces 21px）。
- 右：`NetworkDot`、`GranularityToggle`、`设置` 齿轮、头像。
- 键盘：`Alt+←` 返回；标题条本身不可 Tab 聚焦。

### TaskRail（任务栏）

- 248px；分组标题「今天 / 昨天 / 更早」12px `--fg-mute`。
- 任务项 44px 高：状态点（8px）+ 名称（单行省略）+ 右侧徽标。
- 状态：`进行中`（朱砂实心点 + 呼吸 1.8s）、`需要你确认`（warn 空心点）、`完成`（ok 空心点）、`已暂停`（`--fg-mute`）。
- 徽标「正在另一个窗口进行中」：12px 描边小标签，点击给说明浮层。
- 底部固定：`＋ 新任务`、`我的文件`、`账号`。
- 键盘：`↑↓` 在任务间移动，`Enter` 打开。

### StepCard（**signature 组件**）

这是整套设计唯一必须做对的视觉：**一条 2px 竖轨串起的步骤卡**，把"听了 → 分了 → 在写"变成看得见的施工进度。

- 结构：左侧 2px 竖轨（`--line-strong`）+ 24px 节点 + 右侧卡片（`--surface`，`--r-2`，`1px solid var(--line)`）。
- 节点：未开始=空心 12px；进行中=`--accent` 实心 12px + 外圈 24px 淡色脉冲；完成=`--ok` 实心 + 白色对勾；失败=`--danger` 实心 + 短横。
- 卡片内容（L1）：`③ 正在写第 4 段`（17px/600）+ 右侧耗时 `1 分 12 秒`（13px `--fg-mute`）+ 一行结果说明。
- 卡片内操作：`查看详情`（文字按钮，展开 L2）、失败时 `重试` 与 `跳过`。
- 状态：`折叠（默认）/ 展开（L2）/ 展开并显示具体操作（L3，二次点击）`。
- 动效：完成时仅 200ms 淡入 + 节点填色；**不做位移、不做弹跳、不做彩带**。
- 键盘：整卡为一个 tab 位，`Enter/Space` 展开，`Esc` 收起。
- 无障碍：卡片 `role="listitem"`；进行中卡片 `aria-live="polite"` 区域只播报阶段变化，不逐字播报流式文本。

### ProgressStrip

- 位于中栏顶部，32px 高：`第 3 步，共约 5 步` + 细进度条（2px，`--accent`）。
- 右侧：`已用 3 分 12 秒` + `叫停`（文字按钮，`--danger`）。
- 步数为估算时必须写"约"，不假装精确。

### PermissionPill

- 常驻于中栏顶部右侧或详情抽屉首行；高度 28px，`--r-1`，`1px solid var(--line)`，低视觉权重。
- 三档人话名：`只看看` / `可以改这个文件夹` / `什么都能动`。
- 点击展开：当前档位、它意味着什么、如何改、以及「什么都能动」的倒计时。
- 危险档位：`--danger` 描边 + `30 分钟后自动收回` 文案；**默认永远是「只看看」或「可以改这个文件夹」**。

### DetailDrawer

- 320px 右抽屉，默认 `translateX(100%)` 收起。
- 首屏三行：`权限：可以改「会议纪要」`、`记忆：已用 37%`、`用时：3 分 12 秒`。
- 下方 `▸ 查看详情` 才展开 L2（文件清单、步骤耗时、用了哪个能力）。
- Esc 关闭，焦点回到触发元素。

### ConfirmSheet

这是**安全感的来源**，必须极度克制、极度清楚。

- 居中浮层 480px，`--surface-2`，`--shadow-2`，`--r-2`。
- 标题（人话 + 数量）：`AI 想把 3 个文件改名`。
- 影响清单：`旧名 → 新名` 逐行列出（最多 5 行，超出显示「还有 2 个」）。
- 三个按钮：`允许`（主）、`不允许`（次）、`这类操作以后都允许`（文字按钮，需二次确认）。
- 折叠区：`▸ 查看具体操作` → L3 原文（等宽字体）。
- 键盘：默认焦点在`不允许`（安全默认），`Esc` = 不允许，`Tab` 循环不逃逸。
- **绝不使用红色大按钮做"允许"**；红色只用于危险动作本身。

### FileSpaceCard

- 空间条：`21GB 可用 / 共 25GB`，2px 进度条。
- 副行：`7 天后自动清理最旧的文件`，旁边 `管理` 文字按钮。
- 产物卡：文件名 + 大小 + 来源任务 + 三个动作`打开 / 另存 / 删除`；删除后 Toast 内 `撤销`（10 秒）。

### AccountCard

- 头像（40px 圆形）+ 昵称 + 登录状态徽标（`已登录` / `登录已过期，点此重新登录`）。
- `已连接的账号` 列表：服务名 + `断开` 文字按钮 + 一行说明"断开后它不能再帮你操作这个服务"。
- 奖励：`有 2 个红包待领取` + `领取`；领取后整行淡出，Toast `已领取，可在账号里查看`。

### NetworkDot

- 标题条内 8px 圆点 + 文字 `网络：正常`。
- 展开浮层显示三条线路的人话名：`大文件`、`实时消息`、`普通请求`，各自状态；底部 `出问题了？` + `运行记录导出`。
- 断开时：点变 `--danger`，文案 `网络断开了`，浮层给 `重试` 与 `换用手机热点`。

### CommandPalette

- `Ctrl/Cmd+K` 唤起；顶部输入框 + 分组结果（任务 / 页面 / 动作）。
- `↑↓` 移动、`Enter` 执行、`Esc` 关闭；无结果时给三条示例。

### Toast

- 左下角，`--surface-2`，`--r-2`，最长 5 秒；可带一个动作（`撤销` / `重试` / `查看`）。
- 同时最多 2 条；不遮挡标题条与叫停按钮。

### EmptyState

- 空任务时：Fraunces 38px 一句话 `还没交办过事情` + 三个可直接点的示例（`帮我整理桌面上的发票` 等）。
- 空文件时：`还没有文件，任务完成后会自动出现在这里`。

### OnboardingSteps

- 全屏覆层，仅首次出现，共 3 步：
  1. `它能帮你做什么`（三张示例卡）
  2. `动文件前一定会问你`（示意 ConfirmSheet）
  3. `试一句：帮我整理桌面上的发票`（可直接点「就试这句」）
- 右下 `跳过`，右上 `1 / 3` 进度；完成后写 `localStorage` 不再出现。

### GranularityToggle

- 标题条内两段式控件：`简明` / `详细`；高度 28px，宽 104px。
- 简明：L2 默认折叠，L3 需两次点击；详细：L2 默认展开，L3 一次点击。
- 切换即时生效并持久化；不需要确认。

## 9. 动效

| 场景 | 时长 / 缓动 | 说明 |
| --- | --- | --- |
| 启动入场 | 0 / 60 / 120ms 错位 | 标题条 → 任务栏 → 中栏，各 200ms 淡入 + 上移 8px |
| 步骤卡出现 | 200ms `--ease` | 淡入 + 上移 6px |
| 步骤完成 | 200ms | 仅节点填色 + 卡片内容淡入；**无位移** |
| 流式文字 | 20ms / 字 | 逐字追加，光标 `▍` 1s 闪烁 |
| 抽屉展开 | 360ms `--ease` | `translateX` |
| 确认浮层 | 200ms | 透明度 + 缩放 0.98→1 |
| Toast | 120ms 进 / 200ms 出 | 左下角上移 8px |

**`prefers-reduced-motion: reduce`**：所有位移与缩放取消，只保留透明度切换；脉冲与闪烁停止。

## 10. 无障碍与安全

| 项 | 要求 |
| --- | --- |
| 命中区 | ≥ 40×40px（文字按钮用 padding 补足） |
| 焦点 | 2px `--accent` 环 + 2px offset；`Tab` 顺序为 标题条 → 任务栏 → 中栏 → 抽屉 |
| 对比度 | 正文 ≥ 4.5:1，大字 ≥ 3:1；三套气质均已按此校验 |
| 播报 | 步骤变化、确认弹出用 `aria-live="polite"`；流式文本不逐字播报 |
| 键盘 | `Ctrl/Cmd+K` 命令面板、`Esc` 关浮层、`↑↓/Enter` 列表、`Alt+←` 返回 |
| 危险默认 | 「什么都能动」默认关闭，开启需二次确认，30 分钟无操作自动收回并 Toast 提示 |
| 可撤销 | 删除、覆盖、批量改名一律给 10 秒 `撤销`，而不是只给"已确认" |
| 叫停 | 进行中任务始终可见 `叫停`；叫停需二次确认，文案说明"已完成的 3 步会保留" |
| 数据 | `设置 → 隐私` 显示「数据存在这台电脑上」，给 `导出` 与 `清除本地数据`（需输入"清除"确认） |
